# Frontend - Drops Canyoning Admin

Este es el frontend desarrollado en React para el sistema de reservas de Drops Canyoning.

### Tecnologías usadas:
- React
- Tailwind CSS
- Consumo de APIs con Fetch/axios
- Integración de pagos con PayPal

### Pasos iniciales:
1. Instalar dependencias:
   ```sh
   npm install
   ```
2. Ejecutar el servidor de desarrollo:
   ```sh
   npm start
   ```
